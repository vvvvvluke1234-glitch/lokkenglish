# lokkenglish — IELTS Writing Lexicon

A static IELTS vocabulary study site with topic pages, quizzes, wrongbook, and morphology flashcards.

## Run locally

Open `index.html` in a browser. The site has no build dependencies; all page links and assets are relative.

## Publish

This folder contains only the public website files. Word documents, source materials, and temporary work files are intentionally kept out. GitHub Pages can publish the repository root from `main`; new commits pushed to the publishing branch update the site.
